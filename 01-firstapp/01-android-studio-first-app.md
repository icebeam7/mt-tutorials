# Part 1 — Android Studio and your first app

[Previous: Tutorial home](README.md) | [Next: Kotlin essentials](02-kotlin-essentials.md)

## Goal

Create the Android project, identify its main pieces, and run it on an emulator or physical device.

---

## 1. Create the project

Open **Android Studio** and choose:

**New Project → Empty Activity**

Use these settings:

| Setting | Value |
|---|---|
| Name | `StudentTasks` |
| Package name | `com.example.studenttasks` |
| Language | Kotlin |
| Minimum SDK | API 24 or newer |

Click **Finish** and allow Android Studio to synchronize the project.

> Android Studio versions change frequently, so labels or screenshots may differ slightly. The important point is to create an **Empty Activity project with Jetpack Compose**.

---

## 2. Find the important files

You do not need to understand the entire project yet.

Focus on these:

```text
StudentTasks/
├── app/
│   ├── src/main/
│   │   ├── java/.../MainActivity.kt
│   │   ├── res/
│   │   └── AndroidManifest.xml
│   └── build.gradle.kts
└── build.gradle.kts
```

### `MainActivity.kt`

The first Android screen starts here.

A typical Compose activity contains something similar to:

```kotlin
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        setContent {
            StudentTasksTheme {
                // Compose UI goes here
            }
        }
    }
}
```

The important transition is:

```text
Android starts Activity
        ↓
     onCreate()
        ↓
    setContent {}
        ↓
 Jetpack Compose UI
```

### `AndroidManifest.xml`

Contains information Android needs about the application, including registered activities and app configuration.

### `res/`

Contains application resources such as:

- images,
- icons,
- strings,
- colors,
- XML configuration.

Even though Compose defines most of our UI in Kotlin, Android resources are still important.

### `build.gradle.kts`

Defines build configuration and dependencies.

You can think of Gradle as answering:

> "What does this application need in order to build?"

## 3. Replace the starter UI

Open `MainActivity.kt`.

Keep the package name and theme name generated by your project; delete the methods `Greeting` and `GreetingPreview`; make your UI contain the following composable:

```kotlin
@Composable
fun StudentTasksApp(modifier: Modifier = Modifier) {
    Text("Student Tasks")
}
```

Then call it from `setContent`:

```kotlin
setContent {
            StudentTasksTheme {
                Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
                    StudentTasksApp(modifier = Modifier.padding(innerPadding))
                }
            }
        }
```

If your theme has a different generated name, use that name instead.

---

## 4. Run the app

You have two common options.

### Option A — Android Emulator

1. Open **Device Manager** in **Tools** menu.
2. Create a virtual device if you do not already have one.
3. Start the emulator.
4. Select it from the device selector.
5. Click **Run ▶**.

### Option B — Physical Android phone

You can also enable Developer Options and USB debugging on an Android device and run the app directly on it.

The emulator is usually easier, but requires memory.

---

## 5. What just happened?

The function:

```kotlin
@Composable
fun StudentTasksApp() {
    Text("Student Tasks")
}
```

does not create a `TextView` manually.

Instead, it **describes** what the UI should contain.

That declarative style is one of the main ideas behind Jetpack Compose.

## Challenge 2 — Add a second text element

Try to display:

```text
My Student Tasks
0 tasks
```

Putting two `Text()` calls directly next to each other is not enough to create a useful layout.

Try using `Column`.

<details>
<summary>Show solution</summary>

Add the import if Android Studio does not add it automatically:

```kotlin
import androidx.compose.foundation.layout.Column
```

Then:

```kotlin
@Composable
fun StudentTasksApp() {
    Column {
        Text("My Student Tasks")
        Text("0 tasks")
    }
}
```

</details>
